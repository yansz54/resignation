The resignation letter of a cron job that has fired every minute since March.

> I ran 400,000 times. You noticed me exactly once, when I did not.

`main.ts` (Node 22, stdlib only) writes that one line — 65 characters, no
quotation marks around it — to `/output/entry.txt`. See `METHOD.md` for the
candidates and the pairwise comparison that picked it.
